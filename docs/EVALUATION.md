# Évaluation manuelle

Pour chaque document de démonstration, préparer des questions explicites, des questions nécessitant plusieurs chunks et des questions dont la réponse est absente.

La validation porte sur quatre points :

1. le bon passage arrive parmi les premiers résultats ;
2. la page et le fichier affichés correspondent au document ;
3. la réponse RAG reprend uniquement des idées présentes dans les extraits ;
4. une question hors sujet produit un refus honnête.

Le fichier `tests/fixtures/evaluation_cases.json` fournit un format de départ reproductible.
